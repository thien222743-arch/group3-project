# Dự án nhóm 3 - Web Development

## 🎯 Mục tiêu:
- Tạo môi trường làm việc nhóm và thiết lập công cụ phát triển.
- Phân chia công việc theo frontend, backend, database.

## 👥 Thành viên nhóm:
- Sinh viên thiện: Backend - Node.js + Express
- Sinh viên nguyên: Frontend - React
- Sinh viên linh: Database - MongoDB

## 🗂️ Cấu trúc repository:
- `/frontend`: giao diện React
- `/backend`: API Node.js
- `/database`: cấu hình MongoDB
